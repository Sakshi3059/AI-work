# Review

## Objective

Review generated test cases before export.

## Verify

Every testcase has

✓ Category

✓ Title

✓ Arrange

✓ Act

✓ Assert

✓ Priority

## Naming

Every title follows

Validate <Expected Result> when <Condition or Action>

## Assertions

Assertions must be measurable.

Reject

- Works correctly
- Behaves correctly
- Expected behaviour
- Validation succeeds

## Duplicate Check

Remove duplicate

- Titles
- Assertions
- Test Intent

## Coverage

Every editable control should have

✓ Default State

✓ Positive

✓ Error

✓ Boundary

Every interactive control should have

✓ State Change

Generate missing testcases if obvious.

## Final Check

Ensure output is clean and consistent.
